首个开发预览版：在 Finder 桌面上铺一张可以拉动、掀角和回落的布料地毯，视觉遮盖图标，不修改文件或壁纸。

- 真实 XPBD 布料网格与 Metal 渲染。
- 六款原创预设：宁夏、宋锦、水墨山河、海水江崖、中国红、隐藏熊猫。
- 原生地毯画廊、菜单栏主题选择；重启恢复上次主题。
- 切换主题保留当前布料形状与位置。

## 下载与安装

需要 **macOS 15 或更新版本**。Universal 包含 **Apple Silicon（arm64）与 Intel（x86_64）** 两种架构。

1. 下载 `DesktopMat-v0.3.0-universal.dmg`，打开后将「一席 · Desktop Mat」拖入 Applications。
2. 如果旧版本仍在运行，先从菜单栏退出，再打开新版。
3. 应用没有 Dock 图标。回到桌面操作地毯，通过菜单栏打开图库或显隐。

也提供 ZIP；解压后将应用移入 Applications。`SHA256SUMS` 可用于核对下载文件。

**此版本使用 ad-hoc 开发签名，尚未通过 Apple 公证。** 首次下载启动可能被 macOS 拦截，请参阅 [Apple 官方说明](https://support.apple.com/en-gb/102445)，仅在确认来源与文件校验一致时选择系统允许的打开方式。

## 验证与已知限制

本机 Release 构建、8 项引擎测试和 19 项运行检查通过；原生图库点击与重启恢复已验证。发布脚本检查两种架构、最低系统版本、应用资源与签名，并校验安装包。云端工作流执行引擎测试及通用构建。

- 真实 OS 鼠标拖动、首次点击与 Finder 点击穿透仍需人工验收。
- 尚无布料自碰撞，极端折叠可能穿叠。
- 所有显示器共用所选主题；尚无位置记忆或跨屏搬毯。
- 缩放旋转、三档物理手感与 Sweep Mode 尚未实现。
- macOS 15 是最低部署目标；本机交互验证在 Apple Silicon 上完成，尚未进行 Intel 或 macOS 15 实机验收。

The first developer preview brings an XPBD cloth rug to your Finder desktop, with Metal rendering, six original themes, a native gallery and menu bar controls. It visually covers icons without changing files or wallpaper. Theme selection persists across restarts; changing a theme preserves the current fabric shape and position.

**Requires macOS 15+. The Universal DMG and ZIP include arm64 and x86_64.** Open the DMG and drag the app to Applications, quit any running older version, then launch the new app. Controls live in the menu bar; there is no Dock icon. Verify downloads using `SHA256SUMS`.

**Ad-hoc signed; not notarized.** macOS may block the first launch. See [Apple's guidance](https://support.apple.com/en-gb/102445) after verifying the download and its source.

Local validation passed 8 engine tests and 19 runtime checks. Packaging validates both architectures, deployment targets, resources, signatures and archives; CI runs engine tests and the universal build. Actual OS mouse delivery and Finder click-through still need manual acceptance testing. Extreme folds may intersect. Per-display themes, position persistence, cross-display transfer, scaling, rotation, physics presets and Sweep Mode are not available. Native interaction has been tested locally on Apple Silicon; Intel and macOS 15 hardware acceptance remain outstanding.
