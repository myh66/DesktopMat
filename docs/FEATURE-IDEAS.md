# 可以继续加入什么

保持一席是一件桌面物件：操作直接发生在地毯上，设置只解决真正需要选择的事情。以下是建议优先级，不是已实现功能或发布日期承诺。

## 优先做：让现有玩法更顺手

| 功能 | 用户体验 | 实现与验收重点 |
| --- | --- | --- |
| 暂时固定掀起的角 | 掀开后按一次修饰键或轻点固定，松开鼠标，再点下面的文件；再次操作让它落下。 | 固定点仍属于 cloth 约束，露出的区域真正穿透；清晰、轻量的释放方式，重置与退出可取消。 |
| 快速显隐快捷键 | 一按就露出全部桌面，再按铺回地毯。 | 用户可更改或关闭；避免常见系统快捷键冲突，不为此申请无关权限。 |
| 每屏位置记忆 | 重启后地毯仍在熟悉的位置，每个显示器可记住自己的主题。 | 保存稳定的显示器标识、归一化位置和尺寸；移除显示器后可回到可见区域。 |
| 尺寸与形状 | 小桌垫、长条毯、大地毯；矩形先行，再加入椭圆或圆形。 | 尺寸改变真正更新 mesh、碰撞和 hit testing，不只缩放截图；保留一键恢复。 |
| Soft / Natural / Heavy | 同一张地毯有不同重量与手感，默认 Natural。 | 用质量、弯曲、摩擦、阻尼表达差异；测试稳定性与拖动响应，不只改变动画速度。 |

固定掀角最值得先做：当前「抓角、松手回落」很有趣，但鼠标还在抓着布料时无法同时点选下面的 Finder 文件。固定一个角能把这段交互完整连接起来。

## 其次：把材质和触感做扎实

- **自碰撞与厚度**：减少布料穿叠，让叠在一起的羊毛有实际厚度；先保证稳定，再追求极端揉皱。
- **纤维方向与轻微磨损**：快速扫过后留下短暂、克制的绒毛方向变化，慢慢恢复；细节不要抢走纹样。
- **适配不同机器的质量档位**：用实测帧耗时选择网格与阴影质量；低功耗或闲置时暂停。
- **可关闭的极轻布料声音**：只在抓取和落地时反馈，默认克制，避免持续环境声。

这些变化先服务「真的像铺在桌面上」。不以更多控制项代替更好的默认手感。

## 之后：扩展数字玩具

- **Sweep Mode 视觉扫地**：小扫帚经过时产生纤维痕迹、灰尘或纸屑粒子，朝地毯靠拢。第一版只使用应用自己的视觉元素，不读取或搬动 Finder 文件；需要真实文件操作时必须另行设计明确授权与恢复机制。
- **地毯卷起与展开**：从边缘卷成一束，腾出桌面，再缓慢铺回；依靠网格约束与碰撞，不使用整张图片的 scale / rotate 冒充。
- **少量小物件**：原创的纸片、压角石等应用内物件，增加布料接触玩法；不增加任务管理面板。
- **社区主题包**：有清楚的主题元数据、作者与许可，离线导入和预览；先完善本地格式，再考虑在线目录。
- **跨屏搬毯**：统一桌面坐标系并明确不同屏幕尺寸、缩放与刷新率的交接，不让双屏输入互相抢夺。

## 主题方向

可以增加「竹影」「沙洲」「雨窗」「素麻」「夜海」这类原创自然主题，以及同一纹样的浅色与深色版本。通过织造结构、留白、配色和纤维细节建立差异，避免靠堆叠传统符号。

主题不会默认根据壁纸变色或更换壁纸。若未来加入自动配色，应由用户选择启用，并清楚说明取色方式。

## Product direction in English

Prioritize a latched corner lift, a configurable hide/show shortcut, per-display position memory, a few useful sizes, and three distinct physical feels. Then improve cloth self-collision, thickness and fiber detail. Visual sweeping and community rugs can follow once the basic desktop interaction is reliable. Keep this a small digital toy with direct manipulation and non-destructive defaults.
