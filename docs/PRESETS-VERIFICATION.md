# 0.3 预设与画廊验证

日期：2026-10-08（Asia/Shanghai）。本机 Apple M4、macOS 27.0.1、两个显示器；最低部署目标 macOS 15。

## 已实现

- 六款独立原创程序化纹样：宁夏、宋锦、水墨山河、海水江崖、中国红、隐山熊猫。
- 2048×1408 Metal albedo 与 600×412 画廊预览复用同一 CoreGraphics 绘制流程；显式修正纹理行方向，使山水、海浪在桌面与画廊中方向一致。
- 紧凑原生 SwiftUI 画廊及菜单主题子菜单；主题切换保留粒子位置与布料状态。
- 所有显示器使用所选主题，UserDefaults 记住选择。纹理先全部准备再提交，分配失败保留当前主题。

## 构建与运行检查

`bash scripts/verify-cloth.sh` 执行成功，退出码 0：8 个 Release 引擎测试通过，应用编译、资源打包、Info.plist 与 ad-hoc 签名检查通过。

最终 shader 方向修正后再次运行本机 `--verify`，**19 项检查全部通过**：六款预设真实 GPU 输出、切换保留形状并更新两个显示器，以及原有窗口层级、局部拖动、主体铺展、掀角、重力回落、投影命中与像素预乘检查。输出保存至忽略的 `artifacts/cloth-verification.json`、`preset-*.png` 和 `cloth-*.png`，这些本机日志不提交到公开仓库。

六款静态预览已目视检查，最终水墨 GPU 图像已检查山峰、河流与薄雾方向；画廊窗口已检查三列两行布局、六个按钮、当前选择和底部说明，无文字重叠或截断。公开预设示意图为 `images/rug-presets.png`，由本项目绘图代码生成，未使用第三方视频画面或用户桌面截图。

## 真实原生 UI 检查

使用原生 UI 工具点击宋锦按钮，Accessibility 状态从宁夏切换到宋锦；点击水墨按钮后，状态与本机保存值均为水墨。通过 LaunchServices 重启应用，再读取画廊状态仍选中水墨，验证实际重启恢复。测试结束恢复验证前的熊猫选择，原生状态显示已选中。

画廊在普通窗口层级，因此本次实际点击可完成。此前桌面层级 NSPanel 的坐标操作工具限制仍存在；这些画廊点击不能证明真实地毯拖动、首次点击或 Finder 点击穿透已经通过。对应边界保留在 `INTERACTION-VERIFICATION.md`。
