# 一席 · Desktop Mat 分阶段开发与验收

每个 Phase 都先完成实现，再编译、启动和验证该阶段行为。没有通过对应验收的阶段保留“待验收”，不能由单元测试、build 成功或窗口存在推断桌面视觉效果已验证。

当前代码版本为 0.2：已接入局部 XPBD 布料拖动、四角提升、松手回落、当前投影三角形动态穿透和空闲暂停。部分实现跨越 Phase 2–5；Release 编译、真实 Metal 输出、12 项运行检查及 8 项引擎测试通过。真正的 OS 鼠标派发与完整桌面合成仍待验收，不宣称这些 Phase 已全部通过。实测与工具限制见 `INTERACTION-VERIFICATION.md`；独立引擎与 CPU 采样见 `CLOTH-ENGINE-VERIFICATION.md`。

## Phase 1：真实桌面覆盖与静态地毯

历史状态（0.1）：实现完成；Debug / Release 编译、启动、GPU 输出与实际 WindowServer 层级已通过。桌面完整合成画面、菜单点击和鼠标点选仍待人工验收。详见 `PHASE1-VERIFICATION.md`。以下保留当时验收边界；这些结果不自动作为 0.2 的回归验收。

范围：原生 app bundle、菜单栏最小入口、透明无边框非激活桌面 NSPanel、Metal 静态 mesh 地毯、显隐与退出。先验证用户核心要求的窗口层级。

验收：

- [x] Swift 6 编译成功，部署目标 macOS 15+；生成 `.app` 并由原生启动接口运行。本机系统为 macOS 27.0.1，macOS 15 实机未验证。
- [ ] 应用没有普通主窗口、标题栏或 Dock 式地毯窗口；菜单栏可显隐与退出。
- [x] 窗口运行时层级严格高于 desktopIconWindow、低于 normalWindow（两个连接显示器的实际 WindowServer 元数据）。
- [ ] 桌面上真实 Finder 文件/文件夹/截图/磁盘图标被不透明地毯区域完整遮挡。
- [ ] 普通 Finder 窗口、其他应用窗口正常覆盖在地毯上方。
- [ ] 切换到其他应用后地毯仍可见，地毯不抢键盘焦点。
- [ ] Phase 1 全窗口鼠标穿透；地毯外桌面点击/框选正常。
- [ ] 隐藏与退出后，被遮挡对象立即重新出现；桌面文件与壁纸没有被改写。
- [x] 保存本次实机证据和已验证/未验证边界；Space、全屏及完整多显示器兼容留到 Phase 6。

历史静态版本没有 Cloth Physics、拖动、掀角、折叠或扫地。0.2 已使用覆盖 `NSScreen.frame` 的透明面板，增加 mesh 交互和动态穿透；回归需要重查实体遮挡、普通窗口遮挡、显隐/退出与真实点击。

## Phase 2：平面交互

状态：局部布料拖动已实现，0.2 集成待验收；缩放和旋转未实现，因此本 Phase 尚未完成。

原定范围：拖动、缩放、旋转与变换后的命中。当前拖动已直接接入 cloth：最近粒子先受牵引，周围节点通过约束跟随；没有整个窗口或图片的刚性平移来代替布料。缩放/旋转仍需另行设计与实现。

待验收：0.2 编译运行；真实鼠标操作从正确区域开始；慢拖/快拖与连续拖动自然；普通 App 窗口保持鼠标所有权；不修改文件；隐藏/退出恢复桌面。缩放/旋转实现后再验收变换范围与命中。

## Phase 3：独立布料引擎

状态：基础 XPBD 引擎已实现，独立测试有记录；0.2 集成、视觉手感与完整性能仍待验收，本 Phase 未宣称完成。

当前实现：40 × 30 单元、1271 粒子、2400 三角形；3D 节点位置/速度、120 Hz 固定步长 XPBD、结构/剪切距离约束及三点织线曲率弯曲约束、抗拉伸修正、重力、桌面碰撞、阻尼与近地摩擦。单点局部抓取通过网格传力，松手继续求解；安静后 solver 休眠、Metal 持续绘制暂停，交互唤醒。鼠标穿透轮询仍持续运行。

独立测试覆盖拓扑/法线、局部牵引、角落提升与回落、快速轨迹有限性、桌面接触和休眠；详情见引擎记录。待集成验收：慢拖平整、快拖局部延迟和波纹、桌面摩擦与松手惯性可见、低鼠标延迟、长时间落地稳定，以及偏厚羊毛的手感。完整应用 60 FPS/ProMotion 120 FPS 未验证；CPU 引擎采样和 120 Hz 固定步长不能代替实际帧率证据。

## Phase 4：抓角、掀开与回落

状态：四角局部抬起与释放回落已实现；0.2 真实四角交互、露出区域和折叠视觉待验收。自碰撞与实体厚度未实现，本 Phase 尚未全部完成。

当前实现：四角附近选择真实角节点，鼠标移动距离控制 3D 提升；松手释放抓取，重力与低回弹使布料回落。法线光照、背面材质、变形流苏、投影软阴影与局部折皱遮蔽近似跟随 mesh。没有 scale/rotate/clip-path 提升动画。折叠尚可能互相穿过，阴影/遮蔽属于当前近似实现。

待验收：0.2 编译运行；四角都能用真实鼠标局部抬起；实际桌面在 mesh 移开区域露出；卷曲、自然下垂、布料堆积和折叠阴影的视觉质量；松手轻微波动后稳定；无需移动任何文件。后续增加自碰撞与厚度，再验证严重折叠互相穿透和堆积稳定性。

## Phase 5：动态鼠标穿透

状态：动态窗口级穿透与 drag ownership 已实现，0.2 真实 WindowServer 鼠标路由待验收；本 Phase 未宣称完成。

当前实现：Renderer 与命中查询读取同一布料 mesh，统一使用 `xy + (0.12, 0.42) × z` 投影；主体三角形决定 `NSPanel.ignoresMouseEvents`，外部/揭露区域与阴影不捕获。原生 mouseDown 开始抓取，起始显示器面板保持单个 drag owner，松手/隐藏/重置/重配置释放。local/global monitor 仅观察，不合成或重放 Finder 点击。

待验收：0.2 编译运行；地毯实体区域实际捕获鼠标；外部和掀开的透明区域点击真正到达 Finder 文件；快速跨边界不丢失第一击；拖动越界不突然松手；别的应用/Finder 已开始的拖动不会被抢走；重叠/折叠区域与绘制一致；多次抬角不留下不可点击区域。几何命中测试和程序化鼠标事件不能代替真实 OS 点击揭露区域的验收。

## Phase 6：主题、完整菜单、偏好与多显示器

状态：0.3 已加入六款原创主题、原生画廊、菜单主题选择与全局主题记忆；每屏配置、物理手感、跨屏传递和完整桌面兼容性未完成。

当前实现：宁夏、宋锦、水墨山河、海水江崖、中国红、隐山熊猫六款原创主题；紧凑 SwiftUI 画廊及菜单主题子菜单，切换保留位置和布料状态。UserDefaults 保存显隐与全局主题，所有屏幕使用当前选项；每显示器一个透明 panel 与独立 cloth。一次抓取保留起始显示器所有权，没有把地毯传递到另一个显示器。Soft/Natural/Heavy、完整设置及各显示器位置/主题持久化未实现。0.3 主题检查单独记录在 `PRESETS-VERIFICATION.md`。

待验收/开发：0.2 最小菜单真实点击和两个显示器各自交互；之后实现并验证宁夏毯、宋锦、水墨山河、海水江崖的实机材质效果和独立配置；跨屏传递需单独实现；热插拔/睡眠唤醒/缩放变化正确；浅色/深色/动态壁纸不被修改；多个 Space、Show Desktop、Mission Control、Stage Manager、第三方应用全屏和多显示器分别记录通过/受限/未验证状态。当前 `.fullScreenNone` 保留桌面行为，第三方全屏兼容未承诺；完整菜单项必须有实际功能。

## 后续独立项目

Sweep Mode、极轻布料音效、社区主题包及真实 Finder 图标位置操作在上述核心阶段稳定后单独规划。默认非破坏性模式始终优先；任何真实文件操作不得混入当前 MVP。进一步的玩法建议见 `FEATURE-IDEAS.md`。
